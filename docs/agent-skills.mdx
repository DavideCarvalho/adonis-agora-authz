`@adonis-agora/authz` and `@adonis-agora/authz-react` ship [Agent Skills](https://agentskills.io):
short `SKILL.md` files that tell a coding agent how to use the library, the patterns to follow and
the mistakes to avoid. They live inside the npm package (its `skills/` folder), so they always match
the version you installed: upgrade the package and the skills come with it.

## Skills in these packages

| Skill | Package | Load it when |
| --- | --- | --- |
| `authz-setup` | `@adonis-agora/authz` | installing and configuring authz, choosing auto-created or migrated RBAC tables, seeding roles and permissions, or mapping your user model to a `{ type, id }` reference |
| `authz-decisions` | `@adonis-agora/authz` | checking a permission or role in controllers, jobs, ace commands or Edge templates, wiring the Bouncer abilities, tuning the super-admin hook, or caching grants per request |
| `authz-route-guards` | `@adonis-agora/authz` | keeping routes behind a role or permission with `requireRole`, redirecting guests or denied users, letting another app in, or gating an Agora dashboard with `authorizeByRoles` |
| `authz-query-scopes` | `@adonis-agora/authz` | listing only the rows a user may access with `accessibleBy`, registering per-resource scope filters, or debugging a scope that returns zero rows |
| `authz-roles-tenancy` | `@adonis-agora/authz` | wiring roles from several sources, finding everyone who holds a role, making checks tenant-aware, or choosing between `superAdminRoles` and a `roleGrants` wildcard |
| `authz-react-ui` | `@adonis-agora/authz-react` | hiding UI by permission or role in Inertia + React, pushing effective grants to the frontend with `buildAuthzShare`, or testing gated components |

## Load them with TanStack Intent

[TanStack Intent](https://github.com/TanStack/intent) finds the skills in your installed packages
and tells your agent when to load them.

```bash
npm i -D @tanstack/intent    # pnpm add -D @tanstack/intent
npx intent install
```

The first `intent install` runs in a terminal: it asks which packages' skills to allow (saved as
`intent.skills` in your `package.json`) and writes a short skill-loading block into `AGENTS.md`
(or into the `CLAUDE.md`, `.cursorrules` or `.github/copilot-instructions.md` that already carries
it). To allow every Agora library without the prompt, for example in CI, add this to
`package.json` first:

```json
{
  "intent": { "skills": ["@adonis-agora/*"] }
}
```

Then your agent, or you, can list and load them:

```bash
npx intent list
npx intent load @adonis-agora/authz#authz-setup
```

`npx intent hooks install` adds hooks that remind Claude Code, Codex and Copilot to load a matching
skill before editing. Without Intent, point your agent at
`node_modules/@adonis-agora/authz/skills/<skill>/SKILL.md` (or
`@adonis-agora/authz-react/skills/...`).

See [AI agent skills](/docs/agent-skills) for every Agora library that ships skills.
